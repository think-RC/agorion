# Roadmap

Agorion は現在、構想と設計を進めています。以下は方向性を示す高レベルなロードマップであり、提供時期や実装順を確約するものではありません。

## 1. 基盤を定義する

- 社会課題をどのように登録・整理するか
- 事実、市民認識、因果、議論、政策をどう分けるか
- 公平性、透明性、プライバシーをどう守るか

## 2. 社会課題の正本を作る

- 社会課題ページ
- 関連ニュース、行政資料、統計、論文の索引
- 地域、関連課題、論点の整理

## 3. 課題の構造を可視化する

- 原因、影響、関連性
- 根拠と条件
- 時系列の変化

## 4. 市民の認識と議論を接続する

- 問題認識とフォロー
- 論点、主張、根拠、反論
- 一人一票性と匿名性の両立

## 5. 政策と政治過程を接続する

- 政策案、法案、予算、議会、行政対応
- 政党・政治家・自治体の公開情報
- 実施状況と検証

## 6. 公共的な情報基盤へ育てる

- 説明可能な集計と編集履歴
- 異議申立てと外部検証
- Logrionとの議論構造連携

# Roadmap

Agorion は現在、構想と設計を進めています。以下は方向性を示す高レベルなロードマップであり、提供時期や実装順を確約するものではありません。

## 1. 基盤を定義する

- 社会課題をどのように登録・整理するか
- 事実、市民認識、因果、議論、方針支持、社会的対応シグナル、政策をどう分けるか
- 公平性、透明性、プライバシーをどう守るか

## 2. 社会課題ごとの議論マップを作る

- 社会課題ページ
- 関連ニュース、行政資料、統計、論文の索引
- 地域、関連課題、論点の整理
- 主張、根拠、反論、未解決点、対応方針の接続

## 3. 課題の構造を可視化する

- 原因、影響、関連性
- 根拠と条件
- 時系列の変化

## 4. 市民の認識を接続し、議論を深める

- 問題認識とフォロー
- 不足する根拠、未回答の反論、前提の衝突、代替案の提示
- 一人一票性と匿名性の両立

## 5. 方針への支持を社会的対応シグナルへつなぐ

- 「この方針を支持する」という版管理された意思表示
- 法改正、行政運用、予算、監査、民間慣行、追加調査等の具体的な要請
- 根拠、反論、少数意見、未解決点を伴う透明な発信

## 6. 政策と政治過程を接続する

- 政策案、法案、予算、議会、行政対応
- 政党・政治家・自治体の公開情報
- 社会的対応シグナルへの応答、実施状況、効果、副作用の検証

## 7. 公共的な情報基盤へ育てる

- 説明可能な集計と編集履歴
- 異議申立てと外部検証
- Logrionとの議論構造連携

# Agorion

Agorion は、社会に散在するニュース、行政資料、統計、論文、議会資料、政策、市民の認識を、**社会課題ごとの議論マップとして結び直す**プロジェクトです。

ニュースサイトでもSNSでもありません。出来事や投稿を消費するのではなく、社会課題ごとに情報を蓄積し、論点、主張、根拠、反論、未解決点、対応方針を一つの構造でたどれるようにします。そのマップを使って議論を深め、形成された方向性への支持を、法改正などの対応を社会へ求めるシグナルとして示せる場所を目指します。

> **出来事ではなく、課題を見る。**

## 目指すもの

Agorion が目指すのは、日本社会の公共的アジェンダ、社会課題、政策議論を構造化し、議論から対応までをつなぐ公共的な議論マップです。

- 社会課題を継続的な「課題カルテ」として整理する
- 課題にニュース、行政資料、統計、論文、政策を結び付ける
- 課題同士の関係や因果を、根拠とともに可視化する
- 市民が何を問題と認識しているかを可視化する
- 論点、主張、根拠、反論、未解決点、政策案を議論マップとして整理する
- 「この意見を支持する」等の立場を重ね、議論が深まるべき箇所を見つける
- 不足する根拠や未回答の反論を示し、議論を深める
- 「この方針を支持する」という意思を、反対意見や留保とともに社会的対応シグナルへつなぐ
- 社会の応答、実施結果、副作用を議論マップへ戻す

Agorion は、日本社会をより良くすることにコミットします。ただし、個別政策の正解を運営が独占的に決めることはしません。

## 基本姿勢

- 完全な価値中立を装わず、民主的意思形成、透明性、検証可能性、説明責任、多元性を支持する
- 異なる立場へ同じ掲載・評価基準を適用し、公平な手続きを重視する
- 事実、市民の認識、因果、価値判断、政策を混同しない
- AI は候補生成と整理を支援するが、重要な構造を無根拠に確定しない
- 運営自身も監査と説明の対象とする

詳しくは[Concept](docs/concept.md)と[Charter](docs/charter.md)を参照してください。

## Logrionとの関係

Agorion と Logrion は別のサービスですが、「構造を可視化する」という思想を共有します。

- **Agorion**：社会課題ごとの公共的な議論マップを育て、支持、社会的対応、実施結果まで扱う
- **Logrion**：個々の会話や既存議論を深く解析し、論点、根拠、前提、反論、未解決点を検証する

Agorion 自身も議論構造を保持しますが、目的は社会課題をめぐる公共的意思形成と社会的対応への接続です。将来は、Agorion 上の議論を Logrion がさらに深く解析し、その結果を議論マップへ戻す連携を構想しています。
